What this protocol is

Traditional byte-level signatures fail when documents undergo benign transformations (PDF/A archiving, OCR, locale formatting). SDP-1 commits to a document's semantic claims using Merkle trees, producing per-claim cryptographic inclusion proofs and classifying change severity across a 5-level taxonomy.

Semantic Commitment (&mathcal;K) — signed Merkle root of canonical claim hashes SHA-256("SDP:leaf:" || h_i).

Canonicalization Pipeline (&mathcal;C) — deterministic normalization (Unicode NFC, whitespace collapse, currency/date coercion) preserving legal semantics.

Merkle Inclusion Proof (π) — per-claim cryptographic proof verifying exact untouched and modified fields.

Protocol mapping: SDP-1 provides a verifiable semantic delta evidence layer that operates directly on top of EUDI Wallet & eIDAS 2.0 Qualified Electronic Signatures (QES) and Verifiable Credentials (VCs).

Fail-Closed Security Guarantee: 12 attack scenarios (byte tampering, currency swaps, claim insertions/deletions) fail closed.
